# ОБОРОТ — магазин виниловых пластинок

Витрина интернет-магазина винила: каталог с честной оценкой состояния,
подбор пластинки по настроению, корзина, «полка» и гид для тех, кто покупает
первую пластинку в жизни.

Статический сайт: чистые HTML, CSS и JavaScript, без сборки и зависимостей.

```bash
# открыть локально
python3 -m http.server 8000
# затем http://localhost:8000
```

Или просто открыть `index.html` в браузере.

---

## Что внутри

| Файл | Что делает |
|---|---|
| `index.html` | Разметка всех экранов |
| `assets/css/style.css` | Оформление, тёмная тема, адаптив от 360 px |
| `assets/js/data.js` | Каталог: 50 пластинок, 8 позиций техники и ухода, 3 набора |
| `assets/js/covers.js` | Процедурная графика: обложки и иллюстрации товаров |
| `assets/js/app.js` | Фильтры, корзина, полка, подбор, гид по состоянию |
| `docs/research.md` | **Анализ рынка, аудитории и конкурентов** |

## Что умеет

**Каталог.** Поиск, сортировка (популярность, цена, год издания, алфавит) и
фильтры: жанр, цена, состояние диска, особенности — цветной винил, 180 г,
двойники, б/у, раритеты, «новичкам», аудиофильские издания. Активные фильтры
показаны чипами, каждый снимается по отдельности. На телефоне панель фильтров
свёрнута, счётчик на заголовке показывает, сколько условий применено.

**Честный грейдинг.** Каждая пластинка отгрейдована по стандарту Goldmine,
диск и конверт — **раздельно**. Интерактивная шкала M → NM → VG+ → VG → G
рисует поверхность пластинки: чем ниже грейд, тем больше царапин и пыли.
Из шкалы можно сразу отфильтровать каталог.

**Подбор по настроению.** Три вопроса — настроение, опыт, бюджет — и подборка
из четырёх пластинок. Для новичков поднимаются запечатанные издания, для
коллекционеров — раритеты и единственные экземпляры.

**Вертушка.** Кнопка «На вертушку» в карточке ставит пластинку на проигрыватель
на главной: обложка выезжает из конверта, диск крутится, тонарм опускается.

**Кот в мешке.** Жанр плюс потолок цены — магазин выбирает пластинку сам,
со скидкой 15%.

**Корзина и полка.** Обе живут в `localStorage` и переживают перезагрузку.
В корзине — полоса прогресса до бесплатной доставки, на полке — подсчёт,
сколько это музыки по времени.

## Про данные и картинки

Это демонстрационный проект.

- **Альбомы настоящие**, состав каталога собран по реальной структуре спроса
  на российском рынке 1П 2026 (русский рок, классический рок, саундтреки,
  классика, джаз) — см. `docs/research.md`.
- **Цены, наличие и состояние — учебные.** Они лежат в коридоре реального
  рынка, но это не прайс работающего магазина.
- **Вся графика нарисована кодом.** Обложки строятся процедурно из палитры
  и стиля, заданных в `data.js`, и детерминированно выводятся из `id` товара —
  одна и та же пластинка всегда выглядит одинаково. Издательский арт не
  копируется и не заимствуется.

### Как поставить настоящие фотографии

В `renderCover()` есть точка подмены: если у позиции задано поле `image`,
показывается фотография, если нет — рисуется обложка. Менять код не нужно:

```js
{
  id: 'kino-zvezda', artist: 'Кино', title: 'Звезда по имени Солнце',
  image: 'assets/img/kino-zvezda.jpg',   // ← достаточно добавить эту строку
  ...
}
```

Права на фотографии обложек принадлежат правообладателям — если брать их
с чужих площадок, это надо согласовывать отдельно.

## Совместимость

Проверено в Chromium на десктопе (1440 px) и на iPhone 13 (390 px):
горизонтального скролла нет, ошибок в консоли нет, все сценарии
(фильтры, корзина, полка, модалка, подбор, кот в мешке, гид по состоянию)
проходят автотесты. Учтён `prefers-reduced-motion`.
